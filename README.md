# SharedSpaceManager
SharedSpaceManager es una plataforma web orientada a la gestión y reserva de espacios compartidos, como salas de reuniones y puestos de coworking. El sistema permite administrar reservas, gestionar usuarios según roles y visualizar la disponibilidad de los espacios de manera organizada. Su propósito es mejorar la organización de los recursos y reducir conflictos de horarios mediante una interfaz simple e intuitiva.
## Instalacion y ejecucion
Para ejecutar el proyecto correctamente se recomienda seguir estos pasos:
- Obtener archivos del proyecto
  - Opcion A: clonar el repositorio "SharedSpaceManager"
  - Opcion B: descargar el archivo .ZIP del proyecto y luego descomprimirlo
- Ingresar dentro de la carpeta "maqueta"
- Abrir el archivo "index.html" para abrir el proyecto de manera local.
